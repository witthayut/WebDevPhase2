# WebDevPhase2
Project Description

Phase II allows you to implement the front-end and back-end parts of your web application,
designed in Phase I. 

You will implement the web application as follows:
• Front-end pages use HTML, CSS, and JavaScript; all pages are hosted on the front-end
server.

• The back-end of your web application, including the database and web services, is hosted
on the back-end server, which uses Node.js.

• In addition, you will interact with your own web services and a public web service using
JavaScript.
